# DY³⁺ Polaris

面向稀土发光材料学习与科研辅助的多智能体教学系统。系统以教学任务为主线，同时保留科研问答、证据检索和材料机制分析能力。

## 核心闭环

一次真实任务依次经过：

1. 学情诊断：读取学习者画像与已确认的学习状态，决定解释深度；
2. 知识生成：围绕问题检索领域知识并形成教学讲解；
3. 科学审核：核对答案、证据和限制条件，必要时触发修订或拒绝；
4. 导学决策：给出下一步学习行动，并把真实学习事件接回学习者连续画像。

前端提供五个相互连通的空间：学习总览、任务工作区、协同分析、知识证据和成长路径。页面只消费公开运行事实，不展示私有候选对象、内部推理或模拟进度。

## 真实性边界

- 答案、审核、证据和协同轨迹来自同一次任务运行；
- 没有真实来源时不伪造论文、图表、实验数据或知识关系；
- 长篇个性化讲义只有在真实模型生成并通过 Reviewer 后才作为生成资源发布；
- 未配置模型时仍可运行受审核的教学骨架和证据阅读，但不会将模板或证据拼接冒充模型生成；
- `.env`、运行数据、日志和本机连接器配置不会进入版本库。

## 本地运行

要求 Python 3.10 或更高版本。

```powershell
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
python -m dy3_polaris.main --host 127.0.0.1 --port 8000
```

浏览器访问 <http://127.0.0.1:8000/>。

模型配置写入本地 `.env`。不要提交真实 API Key。若只配置一个可用模型，系统按单一真实模型运行；只有配置并验证多个提供方后，多模型路由才会启用。

## 验证

```powershell
python -m pytest tests/test_l7_frontend.py -q
python -m pytest tests/l5 -q
```

重点回归覆盖：四 Agent 主链、答案/证据/审核一致性、质量回流、个性化资源、学习者连续画像、知识概念与关系、教学记忆、API 兼容和私有数据防泄漏。

## 目录

- `src/dy3_polaris/l2/`：学习者事实、BKT/IRT 与画像服务
- `src/dy3_polaris/l3/`：知识、检索、证据与内容合成
- `src/dy3_polaris/l5/`：多智能体协同、教学决策与主运行链
- `src/dy3_polaris/l7/static/`：五空间原生 JavaScript 前端
- `tests/`：分层测试与真实主链保护测试

## 当前产品定位

DY³⁺ Polaris 不是通用聊天机器人，也不把固定演示数据包装成个性化结果。它将“帮助用户解决当前科研问题”的助手能力，纳入“诊断—教学—审核—练习—成长更新”的持续教学过程。
